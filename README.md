# Ammar Shaikh — Portfolio Website

Personal portfolio website for **Ammar Shaikh**, Full-Stack & MERN Developer based in Surat, India.

## Tech Stack

- **Vite** — Fast frontend tooling and dev server
- **Vanilla HTML5, CSS3, JavaScript (ES6+)**
- **Modern Responsive & Interactive Web Animations**

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/ammar3040/portfolio-website.git
cd portfolio-website
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Build for Production

Build the optimized production assets:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
